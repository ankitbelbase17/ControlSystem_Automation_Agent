## 🚀 Quick Commands

### Most Common
```bash
# Run the system
python main.py

# Run tests
python test_runner.py

# View logs
tail -f app.log
```

### Setup
```bash
# Copy config template
cp .env.example .env

# Edit config
nano .env  # Add Azure credentials

# Verify setup
python test_runner.py
```

### Development
```bash
# Check imports
python -c "from agents.openmodelica_agent import OpenModelicaAgent; print('✓')"

# Check config
python -c "from config.config import Config; print(Config.AZURE_OPENAI_ENDPOINT)"

# Check OpenModelica
omc --version
```
